شاورما ريم - طريقة التشغيل

الطريقة الأسهل (موصى بها): افتح رابط البرنامج على الموبايل، ومن قائمة المتصفح اختر "إضافة إلى الشاشة الرئيسية".

إذا وصلك ملف zip:
1) فك الضغط (من تطبيق الملفات).
2) ارفع الملفات على GitHub Pages (Add file > Upload files) وفعّل Pages، ثم افتح الرابط من الموبايل.
3) أو افتح index.html مباشرة بمتصفح Chrome على الأندرويد.

ملاحظة: بيانات كل جهاز مستقلة، وخذ نسخة احتياطية من داخل البرنامج بشكل دوري.
